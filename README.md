# Лабораторная работа №2, задание 4

## Overview

Программа читает данные из текстового файла, выполняет их обработку и записывает результат в новый текстовый файл.  
Основные функции:
- Чтение входного файла `data/input.txt`.
- Обработка
- Сохранение результатов в `data/output.txt`.
