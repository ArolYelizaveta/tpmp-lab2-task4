# Отчёт о тестировании программы фильтрации книг

**Программа:** `book_filter`  
**Задача:** Из входного файла с данными о книгах (формат: название;фамилия;имя;год;издательство;себестоимость;цена;прибыль) выбрать только те записи, у которых фамилия автора начинается с заглавной буквы «К» (кириллица). Результат сохраняется в выходной файл.

## Условия проведения тестов
- Кодировка входных файлов: UTF-8.
- Разделитель полей: `;` (точка с запятой), пробелы вокруг разделителя не допускаются.
- Программа собрана командой `make`, запуск: `./book_filter <input> <output>`.
- Версия компилятора: gcc (Ubuntu 11.4.0-1ubuntu1~22.04) 11.4.0

## Тестовые набор

### Тест №1. Корректные данные с несколькими подходящими книгами

**Входной файл `test1_input.txt`:**
Война и мир;Толстой;Лев;1869;Русский вестник;100.0;250.0;150.0
Преступление и наказание;Достоевский;Фёдор;1866;Русский вестник;80.0;200.0;120.0
Капитанская дочка;Пушкин;Александр;1836;Современник;50.0;120.0;70.0
Кому на Руси жить хорошо;Некрасов;Николай;1874;СПб;80.0;150.0;70.0
Басни;Крылов;Иван;1809;СПб;20.0;50.0;30.0

*Ожидаемый результат:* Басни;Крылов;Иван;1809;СПб;20.00;50.00;30.00
*Фактический результат:* Басни;Крылов;Иван;1809;СПб;20.00;50.00;30.00
